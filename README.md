# C Quiz Game

A simple terminal-based quiz game written in C. a learning project btw!

---

### Features

- 10 multiple-choice questions
- Score tracking
- loads questions from a file
- Percentage calculation
- Input validation

---

### Concepts that i got hands on 

- Functions
- Function Arguments
- File I/O
- User Input
- Return Values

---

### Future Improvements

- Better UI
- Tiers for level based game
- User data

---

### How to Compile and Run (With gcc, clang or minGW compiler installed)

**With Clang**
```bash 
clang main.c questions.c -o main && ./main
```

**With Gcc**
```bash
gcc main.c questions.c -o main && ./main
```
